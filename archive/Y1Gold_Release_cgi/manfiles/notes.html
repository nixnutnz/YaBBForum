General Notes
  • YaBB is distibuted free of charge: do not abuse this by using code in other programs or selling any portions of YaBB without permission. We encourage everyone to donate in some form or another (see yabb.org for more info). By using YaBB you agree to the terms described in the YPL (license). Please view the license page of this manual for more information.
  • Support is free of charge at http://yabb.xnull.com/community/ at a "first-come, first-serve basis". Donations (explained on yabb.xnull.com) will get you different amounts of Preference for Support over those who do not donate.
  • View the "Whats was new through Y1F" page for information on upgrades and bug fixes from previous versions of YaBB through YaBB 1 Final. View the "What's Changed for this Release?" page to see the bug/security fixes and new features in this YaBB release.
  • This is the FINAL version of YaBB 1 (Gold). Unless major bugs are reported, no further complete releases will be distributed by http://yabb.xnull.com until YaBB version 2 is completed. This means that this version is the last version of YaBB 1 that will be supported. NO MORE CODE SUPPORT will be offered for YaBB 1.
  • For any help on installation and customization, please visit us at http://yabb.xnull.com.
  • If you visit YaBB's support forum for help or to report bugs, please be aware of what forum you are posting in. The "YaBB News" forum is not for bugs.. they go in the "Bug Reports" forum. Security leaks need to be email to jeff@xnull.com (please do not post them on any forum for obvious reasons).
  • Code Mods are available from various locations. These are files that work with [CV]XXL's Board Modifier program and will change the code to add new features or fix bugs. Mod files are NOT supported by YaBB, therefore, do not report bugs with them to YaBB or X-Null staff. We may reply to questions posted on the forum from time to time about trouble with a mod, but nothing more.
